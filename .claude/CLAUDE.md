## 产品方案总览

### 一句话定位
"像聊天一样记账——说一句话，AI自动帮你分类、归档、分析。"

核心洞察：传统记账App需要手动填表单（金额、分类、账户、备注、时间），一笔记账耗时30秒以上，用户3天内放弃率超过80%。AI无感记账把输入成本压缩到3秒，让"坚持记账"这件事不再需要毅力。

### 数据模型（7字段）

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `id` | str | 唯一标识，格式 rec_序号 | `rec_001` |
| `amount` | float | 金额（正数） | `35.00` |
| `type` | str | 消费类型 | `支出` / `收入` |
| `category_main` | str | 一级分类 | `餐饮` |
| `category_sub` | str | 二级分类 | `三餐正餐` |
| `note` | str | 备注，AI从用户原话提取 | `公司楼下食堂` |
| `timestamp` | datetime | 消费时间，默认当前 | `2026-07-16 12:30` |

> **产品决策记录**：支付方式字段在方案评审中被砍掉。原因：用户自然语言中极少包含支付信息（"午饭35块"不会说"微信付了午饭35块"），强行保留会导致90%记录填"未知"，数据无分析价值。这体现了"做减法的勇气"——产品经理的核心能力不是堆功能，而是判断什么不做。

> **产品决策记录**：选择二级分类而非一级或三级的原因——一级太粗（"餐饮"看不出是日常还是聚餐），三级太细（AI容易分错，用户也懒得选）。二级是"AI准确率"和"分析深度"之间的最优平衡点。

### 交互设计：AI猜测 + 用户确认

```
用户输入："中午食堂花了35块"
          ↓
   DeepSeek API 解析（结构化Prompt）
          ↓
界面展示确认卡片：
┌─────────────────────────────────┐
│ ✅ 已识别：午餐 35.00元           │
│     🍚 三餐正餐                  │
│     📅 2026-07-16 12:00         │
│     [确认入账] [修改] [取消]      │
└─────────────────────────────────┘
          ↓ 用户点确认
      正式入账 → 更新列表 & 汇总
```

> **产品决策记录**：选择"AI先猜+用户确认"而非"AI反问"。理由：90%的场景AI能猜对，用户只需点确认（零摩擦）；10%猜错了用户点修改（有出口）。如果反问，100%的用户都会被中断输入节奏。"容错+可修改"比"零容错+必反问"的用户体验更好。面试表达："这是对AI能力边界的诚实设计，不假装AI 100%准确，但也不因此牺牲体验。"

### 技术架构（比喻版）

| 技术 | 比喻 | 在项目中的作用 |
|------|------|--------------|
| **Streamlit** | 搭乐高积木 | 不用写HTML/CSS就能拼出网页界面，Python代码直接生成UI |
| **DeepSeek API** | 雇了一个24小时不休息的记账员 | 把"午饭35块"翻译成 `{amount:35, category:"三餐正餐"}` |
| **Pandas DataFrame** | 一张超级Excel表格，存在内存里 | 存所有记账记录，支持筛选、汇总、画图 |
| **session_state** | 浏览器和服务器之间的"便利贴" | 页面刷新时数据不丢，每次对话都往表里加新行 |

## 自定义命令

### /init
初始化项目环境。创建 requirements.txt、.gitignore 文件，安装必要的 Python 库（streamlit、openai、pandas）。创建 app.py 主文件并写入一个基础的 "Hello World" Streamlit 页面。

### /build-mvp
基于产品方案，搭建"一句话记账"的核心功能。具体包括：
- 一个 Streamlit 聊天式输入框，用户输入消费描述。
- 调用 DeepSeek API（使用 openai 库兼容接口），用 System Prompt 进行自然语言解析，返回结构化JSON。
- 解析失败时的降级处理：提示用户补充信息，而非静默失败。
- 将解析结果展示为确认卡片（金额、分类、时间），用户可点确认入账或手动修改。
- 确认后的记录存入 session_state 维护的 Pandas DataFrame。
- 在界面上显示最新的记账列表和今日/本周支出汇总。
- 使用 Streamlit 原生图表展示分类饼图。
- 包含"撤销上一条"按钮。

### /add-weekly-report
在 MVP 基础上，增加"AI 洞察周报"生成功能。点击按钮后，读取本周记账数据，调用 DeepSeek 生成一份幽默风格的周报并显示。周报需包含：本周总支出、分类排名、与上周对比、一句个性化洞察。

### /deploy
指导我将项目部署到 Streamlit Community Cloud：
- 确保代码、requirements.txt 都已提交到 GitHub 仓库。
- 提醒我在 Streamlit Cloud 的设置中配置 Secrets（DEEPSEEK_API_KEY）。
- 验证部署后的公开链接是否可用。

### /interview-prep
从面试官视角，针对我这个项目提出 5 个可能会被问到的产品/运营问题，并附上回答要点。问题需覆盖：用户痛点洞察、交互设计决策、AI 能力边界处理、数据运营思路、项目迭代方向。
